# Skill Identity

- This plugin uses public `namespace: piro` and `container: codex-plugin`. Pass both explicitly to
  the installed Canon Skill Author scaffolder and validator.
- Keep `metadata.owner: tanaab` and its tag as Canon provenance; public names, descriptions, prompts,
  homepages, and artwork retain the piro identity.
- `piro-skill-author` owns the profile customization; Canon owns the shared standards and tooling.
