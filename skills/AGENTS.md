# Skill Identity

- This plugin uses `owner: pirog`, public `namespace: piro`, and `container: codex-plugin`. Pass all
  three explicitly to
  the installed Canon Skill Author scaffolder and validator.
- Skill ownership is independent of Canon's public namespace and structure. Keep public names,
  descriptions, prompts, homepages, and artwork aligned with the piro identity.
- `piro-skill-author` owns the profile customization; Canon owns the shared standards and tooling.
