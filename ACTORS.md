Owner: pirog
Visibility: Public

This file identifies the humans and agents that reviewed work-planning workflows may consider. It
provides durable focus and goals context, not live identity, availability, repository access,
workload, or assignment authority.

## Entry Contract

Each actor entry provides:

- an exact GitHub handle;
- a kind: `human` or `agent`;
- a concise current focus; and
- a public reviewed goals source when one is available.

Repository discovery policy belongs in [`WORK_REPOS.md`](./WORK_REPOS.md), not in actor entries.

## Authority And Freshness

Registry membership does not prove that an actor is currently available, authenticated, assignable,
or authorized for any repository.

Every workflow must independently verify current identity, repository access, assignability,
workload, and relevant permissions. When a goals source is unavailable, a workflow may use the
concise focus only when its own contract allows that fallback, and it must report the limitation.
